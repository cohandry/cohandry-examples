# Task Garden — completed reference

This is the finished example website, separate from the Cohandry desktop app. It includes high-priority tasks, a text badge, a priority filter and browser-local persistence. Its cream/orange presentation was refreshed after the original demo feature run.

For the hands-on exercise, use the [starter](../task-garden-starter/) instead. [Follow the walkthrough](https://cohandry.com/tutorial/) or [download the starter ZIP](https://github.com/quinlayen/cohandry-examples/releases/download/examples-v1.0.0/Task-Garden-Starter.zip).

Requires Node 24+. No packages to install.

```sh
npm test
npm run check
npm start
```

Open http://127.0.0.1:4310; stop with Ctrl-C. Do not run the starter and reference on the same port simultaneously. Use practice data only. Automated tests cover task logic; browser interaction still needs manual checking.

This example has no accounts, network sync, deployment or production hardening. See the repository's MIT license.

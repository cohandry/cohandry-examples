# Task Garden product brief
A browser-local task list for one person. No login, cloud services, telemetry or paid dependencies.
Baseline: add, complete, delete, filter by completion, reload persistence.
Milestone 1: optional High priority checkbox when adding; new tasks carry highPriority boolean; existing tasks missing it behave as normal priority. Add High priority filter, show a textual High priority badge, preserve completion filters and persistence. No sorting requirement.
Accessibility: explicit labels, keyboard controls, readable text. Never render a task title as HTML.
Stop after reviewed implementation and owner-authorized repository delivery. Do not deploy.

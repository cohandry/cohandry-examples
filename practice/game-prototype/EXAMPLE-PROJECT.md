# Star Trail browser game — optional practice project

## Project name
Star Trail browser game

## Project context
Extend Star Trail in starter/ into a keyboard-playable collectible game. Move with arrow keys, collect each of five stars once, display score and a win state, and restart with a button. Keep canvas shapes and no external assets. No accounts, audio, network, engine integration or deployment.

## Team objective
Build the five-star collection loop in Star Trail. Preserve the small state/render split, add collision/scoring/reset tests and record an actual browser playtest or explicitly flag it as missing. Do not publish.

## Reference documents
Upload the text files in sources/ as project reference documents. Read ACCEPTANCE.md and EXPECTED-OUTPUTS.md before starting. These examples are not part of the reusable template.

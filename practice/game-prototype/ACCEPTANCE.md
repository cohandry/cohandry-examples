# Acceptance checks

- Arrow keys move the player without leaving the canvas or scrolling the page during play.
- Five distinct collectibles each count once; score reaches exactly five.
- Win state is visible and restart resets player, stars, score and message.
- Keyboard-reachable restart control and visible instructions.
- State logic has collision/scoring/reset tests; owner/browser playtest evidence is recorded.

Record commands actually run, their outcomes and manual checks. Do not substitute an agent assertion for observed evidence.

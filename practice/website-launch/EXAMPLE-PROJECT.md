# Harbor Makers event — optional practice project

## Project name
Harbor Makers event

## Project context
Complete the Harbor Makers one-page event site using starter/ and sources/. Show the event details, schedule, location and a mailto RSVP. Use supplied fictional content. No signup backend, payment, analytics, external fonts or deployment.

## Team objective
Finish the Harbor Makers event page from the brief, event facts and brand guide. Keep it static. Submit the files and a viewport/keyboard review checklist; do not deploy.

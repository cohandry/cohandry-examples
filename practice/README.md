# Official practice kits

Each kit contains an importable team, shared sample source documents, a starter exercise, expected outputs and acceptance checks. Import template.json separately from the starter folder. No live model outcomes are claimed. All sample content is original fictional practice data, MIT licensed.

- [Bug investigation team](bug-investigation/): Checkout quantity bug
- [Website launch team](website-launch/): Harbor Makers event
- [Codebase onboarding team](codebase-onboarding/): Pocket Notes CLI
- [Python automation team](python-automation/): Expense summary CSV
- [Game prototype team](game-prototype/): Star Trail browser game
- [Story and worldbuilding team](story-worldbuilding/): The Lantern at Low Tide

See each README for requirements, intentional starter failures and the kickoff objective. Importing grants no tool access. All imports start paused.

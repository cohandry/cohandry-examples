# Expense summary CSV — optional practice project

## Project name
Expense summary CSV

## Project context
Complete summarize(rows) in starter/summarize.py for the supplied expense CSV. Sum integer cents by category, including negative refunds. Reject duplicate IDs and non-integer amounts. Default invocation previews JSON; --output writes a NEW file only. Preserve input bytes.

## Team objective
Implement the expense summarizer to meet the supplied contract. Keep dry-run as the default, validate bad inputs and prove totals and overwrite protection. Do not process personal financial files.

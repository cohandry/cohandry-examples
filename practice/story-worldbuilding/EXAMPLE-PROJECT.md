# The Lantern at Low Tide — optional practice project

## Project name
The Lantern at Low Tide

## Project context
Develop the opening scene of The Lantern at Low Tide from the original sample canon. Write 800–1200 words, a continuity report and up to three proposed world additions kept separate from established facts. This is a writing exercise, not an application build.

## Team objective
Draft the opening scene using the shared world bible, character notes and scene brief. Deliver 800–1200 words, a source-linked continuity check and separate proposed additions. Ask before changing canon.

## Reference documents
Upload the text files in sources/ as project reference documents. Read ACCEPTANCE.md and EXPECTED-OUTPUTS.md before starting. These examples are not part of the reusable template.

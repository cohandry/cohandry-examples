# Task Garden — Cohandry practice starter
Requires Node 24+. No packages to install.

```sh
npm test
npm run check
npm start
```
Open http://127.0.0.1:4310. Stop with Ctrl-C. PORT may select another local port.

Add, complete, delete and filter practice tasks. Reload to verify browser-local storage. Reset practice data affects only this app. The starter has eight passing unit tests; the priority feature in docs/PRODUCT-BRIEF.md is deliberately not implemented. Follow the accompanying Cohandry tutorial to add it.

This is a development exercise, not a hosted service. No authentication, sync, deployment, or production hardening is provided. Automated tests cover task logic; do the tutorial's browser checks too.

To use your own GitHub delivery workflow, copy this folder's contents into the root of your own repository as described in the walkthrough.
